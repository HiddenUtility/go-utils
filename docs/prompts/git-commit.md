## メッセージ形式
- 英語で表示
- **1行目（プレフィックス + 概要）:**
  - 形式: `<type>(<scope>): <簡潔な要約>`
  - 例: `docs(agents): AGENTS.mdのルールと運用方針を更新`
  - 主なtype: `feat` (新機能), `fix` (バグ修正), `docs` (ドキュメント), `refactor` (リファクタリング), `chore` (雑務・設定等)
- **2行目:** 空行
- **3行目以降（詳細）:**
  - 変更内容を箇条書きで具体的に記述する
